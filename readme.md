# SnapchatBoost

Ein Snapchat-Automatisierungs-Bot, um deinen Snapscore auf Snapchat Web einfach zu erhöhen.

## Features
- **Snap Boost**: Automatisches Aufnehmen und Senden von Snaps an Shortcuts.
- **Message Spam**: Spamt vordefinierte Nachrichten in einen ausgewählten Chat.
- **Snap Opener**: Öffnet automatisch eingehende Snaps im Loop.

## Voraussetzungen
Stelle sicher, dass du Python 3 auf deinem PC installiert hast und es im Systempfad (`PATH`) eingetragen ist.

## Installation & Ausführung
1. Öffne Snapchat Web (`https://web.snapchat.com`) in deinem Browser und logge dich ein.
2. Richte ein **Shortcut** (Verknüpfung) in Snapchat ein, das alle Personen enthält, an die du Snaps senden möchtest.
3. Klicke doppelt auf `install.bat`, um alle benötigten Bibliotheken automatisch zu installieren.
4. Klicke doppelt auf `start.bat`, um den Bot zu starten.

## Kalibrierung
Da das Skript die Maus steuert, musst du vor dem ersten Start die Positionen der Schaltflächen auf deinem Bildschirm einspeichern.
1. Starte `start.bat` und wähle **Option 5** (Configure Snap Positions) für den Snap Booster.
2. Folge den Anweisungen in der Konsole: Platziere deine Maus über der jeweiligen Schaltfläche und drücke **Y** auf deiner Tastatur.
3. Wiederhole dies für die anderen Funktionen (Option 6 für Spam, Option 7 für Snap Opener), falls benötigt.
